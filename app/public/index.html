    Subscriptions

    One slot per Claude subscription. Each slot logs in through Claude Code's own browser sign-in, so no password or token is ever typed into this page.

    Add a subscription

    Lowercase letters, digits, - and _, starting with a letter. Not a ccr command such as ls, run or ui.

    Fallback providers optional

    When every subscription is maxed out, the gateway can send the request to one of these instead. A provider without a key is skipped. Keys stay on this machine in a file only you can read.
